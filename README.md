# Templo Motor Website

Official multilingual website for Templo Motor, an auto repair workshop located in Manises, Valencia, Spain.

## Languages

The website is available in:

- Spanish
- English
- Ukrainian
- Russian
- Romanian

Each language has its own URL:

- `/` — Spanish
- `/en/` — English
- `/uk/` — Ukrainian
- `/ru/` — Russian
- `/ro/` — Romanian
